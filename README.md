# 👋 Hi, I'm Bassam Elsayed

### Senior Front-End Developer · React · Next.js · TypeScript

I'm a Front-End Developer focused on building **scalable, performant, and maintainable web applications** with React and Next.js.

I started programming out of curiosity while studying Philosophy, beginning with Python before moving into web development. What started as something I was learning for fun eventually became my career.

Today, I work mainly with **React, Next.js, TypeScript, and modern front-end architecture**, while also having hands-on experience with Node.js, Express, SQL Server, MongoDB, and Supabase.

I enjoy solving difficult problems, improving existing systems, building reusable UI, and learning whatever is necessary to ship a better product.
